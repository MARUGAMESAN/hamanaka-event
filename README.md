# はまなかイベントカレンダー

浜中町のイベント情報をまとめて見られるサイトです。主催者はGoogleフォームから掲載を申請し、管理者がスプレッドシートで「掲載」にチェックを入れたものだけがサイトに表示されます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` / `app.js` | サイト本体 |
| `config.js` | **設定ファイル**（スプレッドシートとフォームのURLを貼る） |
| `data/events.json` | 予備のデータ。`SHEET_CSV_URL` が空、または読み込みに失敗したときに使う |
| `img/favicon.svg` | ブラウザのタブに出るアイコン |
| `img/ogp.png` | LINE・X などでURLを共有したときに出る画像（1200×630） |
| `gas/setup.gs` | 申請フォームの回答シートとサイトをつなぐ Apps Script（リポジトリに置かなくてもOK） |

## セットアップ

申請フォームは作成済み（ https://forms.gle/W5fUZy2moYaimNNK6 ・`config.js` に設定済み）。

1. **フォームの回答をスプレッドシートに出す**
   - フォームの編集画面 →「回答」タブ →「スプレッドシートにリンク」→ 新しいスプレッドシートを作成
2. **スクリプトを入れる**
   - そのスプレッドシートで「拡張機能 > Apps Script」を開き、`gas/setup.gs` の中身を貼り付けて保存
   - 関数 `setup` を選んで実行（初回は権限の許可が出る）
   - 回答シートに「掲載」「日程予定（未確定）」「管理メモ」列が、さらに「公開用」タブができる。既存の5イベントも入る
3. **「公開用」タブをCSVで公開する**
   - 「ファイル > 共有 > ウェブに公開」→「公開用」タブ ＋「カンマ区切り形式（.csv）」で公開し、URLを控える
4. **`config.js` の `SHEET_CSV_URL` に手順3のURLを貼る**
5. GitHubにアップして、GitHub Pagesを有効にする

## 普段の運用

- 申請が届くとメールが来る → 回答シートで内容を確認 → **「掲載」にチェック**
- 日程が仮のときは「日程予定（未確定）」にチェックを入れると「予定」マークが付く
- 開催日を空欄にすると「準備中のイベント」に表示される
- 申請内容の誤字などは回答シートのセルを直接直せばOK
- 掲載をやめるときはチェックを外すだけ（行は消さなくていい）
- 管理者が自分で追加するときも、フォームから入力するのが一番かんたん

## 注意

- 「ウェブに公開」したCSVは、反映まで最大5分ほどかかることがある
- フォームの質問は**名前で**サイトの項目に対応づけている（順番は自由）。質問を追加・名前変更したら Apps Script で `rebuildPublicTab` を実行し直す
  - 「時間」「定員」「申込締切」という名前の質問を足すと、サイトにも表示されるようになる
- カテゴリの選択肢を増やすときは、`app.js` の `CATS` にも同じ名前で追加する（入っていないカテゴリは「その他」として表示される）
- `index.html` をパソコンでダブルクリックして開くとデータを読み込めない。GitHub Pages上か、ローカルサーバー（`python3 -m http.server`）で確認する
